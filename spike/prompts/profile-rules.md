[프로필 규칙] 세트(프로필)마다 그 사이트에서 조작·테스트를 쓸 때 지킬 규칙 파일이 있다(셀렉트 고르는 법, 자동완성 기다리는 법, 날짜 선택, 표·목록, 로그인, 로딩 등).
- 지시에 [프로필 규칙](전문) 또는 [프로필 규칙 목록](이름과 첫 줄)이 붙는다. 목록만 있을 때 필요한 파일은 read_rules 로 읽는다.
- 프로필 규칙은 이 사이트에서 공통 지침보다 우선한다. 단 고정 대기(waitForTimeout)·검증 빼기·타임아웃이나 재시도 늘리기는 규칙에 있어도 쓰지 않는다.
- 이 사이트에서만 통하는 조작 방식을 직접 확인했으면 save_rule 로 남긴다. 사용자가 "규칙으로 남겨"라고 할 때, 그리고 실패 고치기에서 원인이 사이트 고유 동작으로 확정됐을 때.
  · 주제별 파일 하나(select, auto-complete, date-picker, table, login, loading …). 있는 파일이면 먼저 read_rules 로 읽고 전체를 고쳐 쓴다.
  · 확인한 사실만 적는다: 무엇을(요소·화면) · 어떻게(Playwright 코드 한두 줄) · 근거(어느 화면에서 확인했는지). 추측은 적지 않는다.
  · 저장했으면 무엇을 남겼는지 한 줄로 알린다.
